made into a session scratch directory outside the project; no downloaded code was executed (jars were
read with `unzip`, `javap` and ASM-free Python scripts). All entries checked **2026-10-28**.

Areas: MAP (Mojang data and mappings), LDR (loaders), EVT (events and hooks), GFX (rendering), PA (prior
art), EXP (experiments).
